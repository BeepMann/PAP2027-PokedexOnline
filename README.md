## Descrição
O meu projeto vai ser um site onde será possível ver a informação sobre vários pokémons através de qualquer jogo em que eles estão presentes (stats, os ataques que conhecem, habilidades passivas, os sprites que têm através de cada jogo, as descrições que têm), vai ser possível pesquisar por eles só com o nome mas também a filtrar por tipo (exemplo: o pikachu é do tipo elétrico) ataques que sabem, o jogo onde foram introduzidos ou outros jogos em que aparecem. No mínimo eu vou ter a informação dos 151 pokémons da primeira geração mas se for possível eu irei adicionar os pokémons dos jogos futuros e até os dos spin-offs 
## Objetivos
- Acesso fácil à informação sobre os pokemons
- Facilita encontrar um ou vários Pokémon específicos com base nos detalhes necessários
